# Carrara design decisions

Decisions that belong to the Carrara design system. The repository-level decisions (workspace structure, prototype proof, dimension bindings) are in [`docs/adr/`](../../../../docs/adr/README.md).

| ADR | Decision |
| --- | --- |
| [0001](./0001-light-workspace-dark-sidebar.md) | A light workspace with a dark sidebar |
| [0002](./0002-type-and-icons.md) | Inter, JetBrains Mono and Heroicons |

Replacing Carrara retires these decisions with the package; a new design system records its own.
